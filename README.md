# Время намаза

Время намазов по джафаритской методике для любой точки мира: на день и на месяц.
Считает так же, как сайт shiatime.ru (сверено с его таблицами минута в минуту).

- имсак — солнце на 17,7° под горизонтом (Институт геофизики Тегеранского университета);
- фаджр — 16° (Исследовательский центр Лива, Кум);
- восход и закат — появление и исчезновение солнечного диска;
- зухр — прохождение солнцем меридиана (+1 минута);
- магриб — 4,5° под горизонтом;
- полночь — середина между закатом и фаджром;
- белые ночи — имсак и фаджр в середине ночи.

Возможности: поиск места по названию и по карте, геолокация, избранные места, таблица на месяц,
дата по хиджре и конвертор дат, сохранение в PNG, JPG и PDF, печать, работа без интернета (кроме карты и поиска).
